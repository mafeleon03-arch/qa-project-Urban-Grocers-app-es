# Pruebas para el parámetro name al crear un kit en Urban Grocers

Este proyecto contiene pruebas automatizadas para comprobar el campo `name` en la creación de kits de productos de la API Urban Grocers.

- Necesitas tener instalados los paquetes `pytest` y `requests` para ejecutar las pruebas.
- Antes de ejecutar las pruebas, inicia el servidor de Urban Grocers y actualiza la URL en `configuration.py`.
- Ejecuta todas las pruebas con el comando:

pytest create_kit_name_kit_test.py
